# Awesome DESIGN.md

Curated collection from https://github.com/VoltAgent/awesome-design-md — 73 DESIGN.md files + previews.

## Usage

1. Pick a brand: `design-md/<brand>/DESIGN.md` (e.g. `linear.app`, `vercel`, `stripe`, `claude`, `notion`)
2. Copy to project root: `cp design-md/<brand>/DESIGN.md ./DESIGN.md`
3. Tell agent: "build me a page that looks like this DESIGN.md"

## Catalog

See `design-md/` directory — each folder has `DESIGN.md` + `preview.html` / `preview-dark.html`.

Quick browse: `ls design-md`

Examples:
- `design-md/linear.app/DESIGN.md` — ultra-minimal, purple accent
- `design-md/vercel/DESIGN.md` — black/white Geist precision
- `design-md/stripe/DESIGN.md` — purple gradients, weight 300
- `design-md/claude/DESIGN.md` — warm terracotta editorial
- `design-md/notion/DESIGN.md` — warm minimalism, serif headings

Source: VoltAgent/awesome-design-md (MIT). Tokens are extracted public CSS.
